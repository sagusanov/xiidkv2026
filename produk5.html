Kewirausahaan Digital DKV

Mengapa Undangan Digital HTML?

Undangan digital berbasis website adalah salah satu produk digital bernilai jual tinggi di industri kreatif saat ini. Sebagai siswa DKV, Anda tidak hanya dituntut mampu merancang layout visual yang estetik, tetapi juga menguasai cara mengemasnya menjadi landing page interaktif yang siap diakses pengguna melalui tautan unik.

Cepat & Hemat Modal

Dibuat dengan bantuan kecerdasan buatan Gemini AI tanpa biaya server mahal.

100% Responsif

Tampilan fleksibel dan proporsional saat dibuka di smartphone maupun PC.

Hosting Gratis

Dapat dipublikasikan secara langsung menggunakan fitur GitHub Pages gratis selamanya.

1

Membuat File HTML Undangan di Gemini AI

Teknik prompt engineering untuk menghasilkan struktur website satu file lengkap.

Untuk menghasilkan kode website undangan yang elegan dan langsung bisa dijalankan, Anda dapat memanfaatkan Gemini AI. Ikuti alur kerja pembuatan prompt berikut:

Elemen Wajib dalam Undangan:
  • Cover Depan / Hero Section (Nama Mempela, Foto, Tombol Buka Undangan)
  • Kutipan Ayat / Kata Mutiara Pernikahan
  • Profil Mempelai Pria & Wanita (Foto, Nama Lengkap, Orang Tua, Instagram)
  • Rangkaian Acara (Akad Nikah & Resepsi + Hitung Mundur / Countdown Timer)
  • Integrasi Google Maps Alamat Lokasi Acara
  • Galeri Foto Prewedding (Grid Responsif)
  • Formulir RSVP Ucapan & Doa + Rekening Amplop Digital
  • Audio Background (Musik pengiring saat undangan dibuka)
Standar Teknis Kode HTML DKV:
  • Gunakan Single File HTML (CSS & JS di dalam 1 file `index.html`).
  • Menggunakan CDN Tailwind CSS untuk styling modern.
  • Menggunakan CDN Font Awesome 6 untuk ikonik grafis.
  • Gunakan Google Fonts (`Playfair Display` & `Inter`).
  • Menggunakan gambar Unsplash sebagai placeholder sementara.
Contoh Formula Prompt Gemini AI 
Buatkan satu file HTML lengkap (index.html) untuk website Undangan Pernikahan Digital responsif dengan Tailwind CSS dan Font Awesome.

Tema Desain: [TULIS TEMA ANDA, CONTOH: Elegant Gold & Classic Navy]
Nama Pasangan: Romeo & Juliet
Tanggal Acara: 20 Oktober 2026

Persyaratan Teknis & Fitur:
1. Gabungkan semua CSS & JavaScript ke dalam SATU file HTML saja.
2. Gunakan CDN Tailwind CSS dan Font Awesome 6.
3. Fitur Utama:
   - Cover Pembuka (Tombol "Buka Undangan" untuk mengaktifkan musik & memicu efek scroll)
   - Profil Mempelai Pria & Wanita beserta link Instagram
   - Countdown Timer (Hitung Mundur) menuju hari H
   - Detail Waktu & Lokasi Akad & Resepsi (Tambahkan Tombol Petunjuk Peta Google Maps)
   - Galeri Foto Prewedding (Gunakan gambar placeholder Unsplash yang estetik)
   - Fitur Amplop Digital / Hadiah (Nomor Rekening BCA/Mandiri & QRIS dengan tombol Salin No. Rekening)
   - Form Ucapan Doa / RSVP Sederhana (Interactive UI)
   - Musik Latar Belakang (Audio player otomatis aktif saat undangan dibuka)
4. Tampilan rapi, mewah, transisi halus, dan mobile-friendly.
2

Registrasi GitHub & Publish Web (GitHub Pages)

Langkah mudah mempublikasikan website undangan agar berstatus ONLINE dan dapat diakses publik.

A

Buat Akun GitHub

Buka github.com, klik Sign Up. Masukkan email sekolah/pribadi, buat password, dan verifikasi akun Anda.

B

Buat Repository Baru

Klik ikon + di pojok kanan atas → New repository. Beri nama (misal: undangan-romeo-juliet). Pilih Public lalu klik Create repository.

C

Upload File HTML

Simpan hasil kode dari Gemini AI di komputer dengan nama file wajib: index.html. Pilih opsi uploading an existing file di GitHub, drag file tersebut, lalu klik Commit changes.

D

Aktifkan GitHub Pages

Masuk ke menu Settings repository → menu Pages di sebelah kiri. Pada bagian Branch pilih main / root lalu simpan. Link website online Anda akan aktif dalam 1-2 menit!

Catatan Penting Siswa DKV: Nama file utama website HARUS bernama index.html (menggunakan huruf kecil semua). Jika menggunakan nama lain, GitHub Pages tidak akan membaca halaman utama secara otomatis.
