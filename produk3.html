Panduan Lengkap & Sistematis Pembuatan Template Canva Feed & Story UMKM

Materi lengkap yang dipelajari dan dikerjakan oleh siswa.

1 Alur & Konsep Pembuatan (Workflow)

A. Riset & Penentuan Niche (Niche/Tema Usaha)

Sebelum mendesain, tentukan segmen UMKM yang ingin dituju:

  • F&B / Kuliner: Makanan pedas, cafe/coffee shop, katering, kue & bakery.
  • Fashion & Beauty: Busana muslim, skincare, outfit harian, thrift shop.
  • Jasa & Olshop Umum: Agensi digital, cuci sepatu, laundry, gadget.
B. Menentukan Struktur Paket (Ketersediaan Slide/Grid)

Dalam 1 set katalog template Canva, buat paket lengkap yang mencakup:

1. Grid Feed IG (1080 x 1080 px atau 1080 x 1350 px):
  • Hook / Promo Utama (Diskon/Flash Sale).
  • Showcase Produk (Single foto & Carousel multi-foto).
  • Edukasi / Tips (Infografis/Poin-poin menarik).
  • Testimoni / Ulasan Pembeli.
  • Pricelist / Menu.
2. Story IG (1080 x 1920 px):
  • Q&A / Polling Interaktif.
  • Order Flow (Cara Pemesanan).
  • Countdown Promo.

2 Langkah-Langkah Mendesain di Canva

1. Buat File Baru di Canva:
  • Pilih ukuran Instagram Post (Portrait 1080 x 1350 px) agar tampilan lebih luas di layar HP.
2. Tentukan Brand Identity (Aturan Desain):
  • Palet Warna: Gunakan 3–4 kombinasi warna utama (misal: Earthy tone, Pastel, atau Bold Modern).
  • Tipografi: Pilih kombinasi 2 jenis font (1 untuk Heading yang tegas/estetik, 1 untuk Body text yang mudah dibaca).
3. Gunakan Elemen Komersial / Free:
  • Pastikan elemen, foto, dan font yang digunakan adalah elemen Gratis (Free) dari Canva, agar pembeli yang menggunakan akun Canva biasa tidak terkendala watermark.
4. Sediakan Frame / Frame Foto:
  • Gunakan fitur Frame Canva pada area gambar/foto produk agar pengguna tinggal menyeret (drag and drop) foto produk mereka sendiri.

3 Cara Membagikan & Menjual Link Template Canva

Setelah semua desain selesai:

1. Ambil Template Link (Tautan Template):
  • Klik tombol Bagikan (Share) di pojok kanan atas Canva.
  • Pilih opsi Lainnya (More) → Pilih Tautan Template (Template Link).
  • Catatan: Jangan bagikan link kolaborasi biasa (View/Edit Link) agar file master Anda tidak tertimpa/rusak oleh pembeli.
2. Buat File Access Card / PDF Pengiriman:
  • Buat 1 lembar PDF interaktif berisi tulisan "Terima Kasih Atas Pembelian Anda".
  • Sisipkan tombol/hyperlink bertuliskan "KLIK DI SINI UNTUK MENGAKSES TEMPLATE CANVA" yang mengarah ke Template Link tadi.
  • File PDF ini yang nantinya dikirimkan otomatis ke pembeli di platform e-commerce (Shopee/Google Drive).

4 Struktur Tampilan Katalog Web (Kode HTML / Portofolio)

Jika Anda ingin menampilkan karya template tersebut ke dalam web portofolio/katalog (seperti pada halaman produk3.html), gunakan struktur grid berikut:

  • Header/Banner: Judul katalog + deskripsi singkat + tombol menuju toko.
  • Fitur Filter: Kategori per segmen (Kuliner, Fashion, Jasa).
  • Grid Card Item:
    • Gambar Pratinjau (Thumbnail): Foto mockup feed IG.
    • Badge: Indikator "Canva Editable" / "Free Elements".
    • Deskripsi: Jumlah slide (misal: 24 Feed + 12 Story).
    • Nama Pembuat: Nama desainer/siswa.
    • Tombol Aksi: Link ke Preview Canva atau Toko Shopee.
